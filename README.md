## 🎯 Motivação e Propósito

Este repositório foi criado para centralizar e versionar o progresso de aprendizado. O propósito não é apenas armazenar código, mas demonstrar a aplicação prática de conceitos teóricos em cenários reais.

Ele resolve o desafio de manter um registro histórico da evolução técnica, permitindo revisitar soluções para problemas comuns (como validação de formulários, requisições AJAX e estruturação de layouts) e servindo como base de conhecimento para projetos futuros.

## 🛠️ Tecnologias Utilizadas

A stack reflete a progressão do curso, partindo de tecnologias nativas para ferramentas de build modernas:

* **Linguagens Base:** [HTML5](https://developer.mozilla.org/pt-BR/docs/Web/HTML) (Semântica) e [CSS3](https://developer.mozilla.org/pt-BR/docs/Web/CSS) (Estilização).
* **Interatividade:** [JavaScript (ES6+)](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript) e [jQuery](https://jquery.com/) (Plugins, máscaras e animações).
* **Pré-processadores:** [SASS/LESS](https://sass-lang.com/) para escrita de CSS escalável (variáveis e aninhamento).
* **Automação:** [Grunt](https://gruntjs.com/) para minificação de arquivos, compressão de imagens e compilação de estilos.
* **Gerenciamento de Pacotes:** NPM (Node Package Manager).

## 📂 Estrutura do Código

O repositório é organizado modularmente, onde cada pasta representa um tópico ou desafio específico:

```text
Ebac_curso_frontend/
├── ajax/             # Exercícios de consumo de dados assíncronos
├── dom/              # Manipulação de elementos da árvore HTML

├── html/             # Estruturas básicas e formulários
├── jquery/           # Implementação de plugins e interações visuais
├── js/               # Lógica de programação (Arrays, Objetos, Funções)
├── sass/             # Arquivos de estilo pré-processados
