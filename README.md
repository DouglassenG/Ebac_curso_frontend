> Um monorepo (repositório único) dedicado a documentar a evolução técnica e os exercícios práticos desenvolvidos ao longo da especialização em Frontend.

## 🎯 Motivação e Propósito

Este repositório serve como um "Diário de Código". Seu propósito é centralizar o aprendizado prático, permitindo consultar soluções anteriores e visualizar a progressão de complexidade nos códigos desenvolvidos.

Ele resolve o problema de fragmentação do conhecimento, mantendo exercícios de lógica, estilização e manipulação de DOM organizados por módulos de aprendizado.

## 🛠️ Tecnologias e Ferramentas

A stack explorada neste repositório cobre os fundamentos essenciais da Web Moderna:

* **Estrutura e Estilo:** HTML5 Semântico, CSS3 e Pré-processadores (SASS/LESS).
* **Interatividade:** JavaScript (ES6+) e jQuery (Manipulação de DOM e Plugins).
* **Automação:** Grunt/Gulp (Minificação de arquivos e compilação).
* **Controle de Versão:** Git e GitHub Flow.

## 📂 Estrutura do Código

O repositório é organizado por módulos ou tópicos específicos:

```text
Ebac_curso_frontend/
├── ajax/             # Exercícios de requisições assíncronas
├── css/              # Fundamentos de estilização
├── html/             # Estruturação semântica
├── jquery/           # Plugins e interatividade
├── js/               # Lógica de programação (Arrays, Loops, Objetos)
